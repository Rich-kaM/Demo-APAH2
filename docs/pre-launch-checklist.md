# Pre-launch checklist

## Content and brand

- [ ] Confirm exact registered legal name, brand use and required corporate footer/notice details.
- [ ] Review English/French pages, titles, descriptions, service/industry taxonomy and supplied biographies.
- [ ] Verify current expert roles and claims; obtain image rights and written portrait consent.
- [ ] Confirm canonical domain, contact details, social links, logo use and approved favicon/application icons.
- [ ] Supply only verified projects, Actuality, Insights and jobs. Keep each new entry in draft until approval.

## Privacy and operations

- [ ] Qualified counsel approves Privacy, Recruitment, Cookie, Consent, Terms and Legal Notices for every operating jurisdiction.
- [ ] Approve lawful bases, consent language, rights request process, contact owner, retention periods and deletion schedule.
- [ ] Select host, email, database/file storage and malware scanning provider; complete processor/transfer registers and agreements.
- [ ] Configure HTTPS, secrets, verified sending domain, reCAPTCHA keys, positive retention days, mail cap and scanner.
- [ ] Migrate local JSON/in-memory sessions before multi-instance production; implement encrypted backups and tested restore.
- [ ] Set up separate named admin accounts, MFA, recovery and least privilege; limit admin to a private network until ready.
- [ ] Run security threat model, upload testing, dependency/SBOM process, monitoring and penetration review.

## Quality and accessibility

- [ ] Run `npm run check:content` and production build/start checks against rendered French and English routes.
- [ ] Run automated accessibility checks (axe or equivalent) on every template in light and dark mode.
- [ ] Manually review keyboard, screen readers, 200–400% zoom, reduced motion, forms/CAPTCHA, and all error states.
- [ ] Check 320, 375, 768, 1024 and 1440 px widths, portrait/landscape and no horizontal scrolling.
- [ ] Verify every route/link/button, sitemap, canonical/hreflang, metadata, favicon/app icons and current copyright year.
- [ ] Confirm image/font licences and performance/compression; retain uncompressed originals outside public assets.
- [ ] Recheck placeholder scanner and ensure no private source, CV or secret is publicly served.
